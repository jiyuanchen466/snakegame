# Snake Game

一个基于 Qt Widgets 和 C++ 实现的桌面版贪吃蛇游戏。项目使用自绘游戏画布、Qt 资源系统和多组定时器完成移动、动画、关卡、音频与对战逻辑。

## 功能概览

- 固定大小的 1200 x 600 游戏窗口。
- 30 x 15 的游戏地图，每个格子大小为 40 像素。
- 四种游戏模式：
	- **Level Mode**：最多 60 个关卡，按关卡目标收集食物、星星或钻石。
	- **Endless Mode**：无尽模式，持续收集食物并累积得分。
	- **Battle Mode**：双蛇对战，限时 120 秒，比较双方得分。
	- **Surprise Mode**：收集未知道具，随机触发加分、传送、障碍、扣命或加命效果。
- 关卡中支持随机障碍、炸弹、移动炸弹和特殊收集物。
- 背景音乐和音效开关。
- 可调节蛇的移动速度，范围为 1 到 10。
- 关卡进度通过 `QSettings` 保存，应用重启后会保留已通关的最高关卡。
- 使用 Qt Resource System 内嵌图片与音频资源，无需单独复制资源文件。

## 游戏模式

### 关卡模式

关卡模式从当前未通关关卡开始。项目共定义 60 个关卡，每 10 关组成一个阶段：

| 关卡阶段 | 主要机制 |
| --- | --- |
| 1-1 至 1-10 | 收集指定数量的食物 |
| 2-1 至 2-10 | 食物与随机障碍 |
| 3-1 至 3-10 | 收集星星，后半段加入钻石 |
| 4-1 至 4-10 | 食物与定时炸弹 |
| 5-1 至 5-10 | 星星、钻石和移动炸弹 |
| 6-1 至 6-10 | 障碍、星星、钻石以及部分炸弹组合 |

完成关卡后按 `Enter` 进入下一关；通关失败后按 `Space` 重试；按 `Esc` 返回主菜单。

### 无尽模式

持续收集食物，每个食物计 10 分。无尽模式支持暂停，按 `Space` 可以暂停或继续游戏。撞到自己、障碍或炸弹会结束游戏。

### 对战模式

两条蛇同时在地图中移动，游戏开始前有 3 秒倒计时，正式比赛持续 120 秒。双方各自收集对应颜色的食物，每个食物增加 10 分。时间结束或发生碰撞后显示胜负结果。

### 惊喜模式

地图中显示未知道具。收集后随机触发一种效果：增加分数、传送蛇、生成障碍、扣除生命或增加生命。初始生命为 3，生命耗尽后游戏结束。

## 操作方式

### 普通模式

| 按键 | 功能 |
| --- | --- |
| `Up` / `Down` / `Left` / `Right` | 控制蛇的移动方向 |
| `Space` | 无尽模式暂停/继续；失败后重新开始 |
| `Enter` | 关卡完成后进入下一关；全部通关后从 1-1 重新开始 |
| `Esc` | 返回主菜单 |

### 对战模式

| 玩家 | 按键 |
| --- | --- |
| 玩家 1 | `W` / `A` / `S` / `D` |
| 玩家 2 | `Up` / `Down` / `Left` / `Right` |

## 设置

主菜单右下角的齿轮按钮会打开设置遮罩层，可调整：

- **Snake Speed**：蛇的移动速度。
- **Background Music**：背景音乐开关。
- **Sound Effects**：吃到道具、碰撞、胜利和失败等音效开关。

## 项目结构

```text
main.cpp             程序入口
MainWindow.h/.cpp    主窗口、主菜单和设置遮罩层
SnakeGame.h/.cpp     游戏状态、关卡、碰撞、绘制和输入处理
SnakeGame.ui         Qt Designer 界面文件，目前主要窗口内容由代码创建
res.qrc              图片和音频资源清单
SnakeGame.qrc        Qt Designer 资源清单
SnakeGame.vcxproj    Visual Studio Qt 项目文件
SnakeGame.sln        Visual Studio 解决方案
SnakeGame.rc         Windows 应用图标资源
```

## 开发环境

项目文件当前配置为：

- Windows x64
- Visual Studio 2022，Platform Toolset `v143`
- Qt `6.7.0_msvc2019_64`
- Qt 模块：`Core`、`Gui`、`Widgets`、`Multimedia`
- Debug 和 Release 均使用 x64 配置

## 构建与运行

1. 安装 Visual Studio 2022，并启用 C++ 桌面开发工具集。
2. 安装与项目配置匹配的 Qt 6.7.0 MSVC 64 位版本，并配置 Qt VS Tools。
3. 打开 `SnakeGame.sln`。
4. 选择 `Debug` 或 `Release`，平台选择 `x64`。
5. 生成解决方案并运行 `SnakeGame` 项目。

程序启动后会先显示主菜单，选择游戏模式即可开始游戏。

## 实现说明

- `main.cpp` 创建 `QApplication` 和 `MainWindow`，进入 Qt 事件循环。
- `MainWindow` 使用 `QStackedWidget` 在主菜单和游戏页面之间切换。
- `SnakeGame` 继承自 `QWidget`，通过 `paintEvent()` 绘制地图、蛇、道具和状态遮罩。
- 游戏主循环使用 `QTimer` 驱动，另有独立定时器处理动画、炸弹、惊喜效果和对战倒计时。
- 关卡配置由 `getLevelConfig()` 根据关卡编号生成，不依赖外部关卡配置文件。
- 图片和音频通过 `:/img/...`、`:/audio/...` 资源路径加载。
